# SatQuery AI — MVP Scope Matrix

| Feature Module | Priority | Status | Rationale |
|---|---|---|---|
| **3D Earth Globe Canvas** | MUST HAVE | IN DESIGN | Core visual differentiator; realistic continuous spherical representation. |
| **Autonomous Camera Tour** | MUST HAVE | IN DESIGN | Allows the AI to navigate user across multiple significant regions. |
| **Natural Language Query Bar** | MUST HAVE | IN DESIGN | Interface for intuitive queries without GIS domain knowledge. |
| **Structured Intent Parser** | MUST HAVE | IN DESIGN | Translates freeform questions into deterministic spatial/temporal queries. |
| **Vegetation Change Analysis (NDVI)** | MUST HAVE | IN DESIGN | Primary MVP benchmark for multi-temporal remote sensing. |
| **Region Polygon Overlays & Markers** | MUST HAVE | IN DESIGN | Visual grounding of affected areas directly on the globe. |
| **Evidence & Metrics Panel** | MUST HAVE | IN DESIGN | Displays before/after values, % change, sensor, date, and confidence. |
| **Water Expansion Analysis (NDWI)** | SHOULD HAVE | PLANNED | Demonstrates index versatility beyond vegetation. |
| **Urban Built-up Growth (NDBI)** | SHOULD HAVE | PLANNED | Demonstrates multi-band analysis capability. |
| **Temporal Observation Slider** | SHOULD HAVE | PLANNED | Allows side-by-side or sliding comparison of imagery over time. |
| **Voice Agent Interaction** | FUTURE | DEFERRED | Post-MVP interface enhancement; core workflow must function first. |
| **Optical + SAR Multimodal Fusion** | FUTURE | DEFERRED | Requires specialized radar processing pipelines. |
| **Public Landing Page** | FUTURE | DEFERRED | Application opens directly into SatQuery Mission Control. |
| **User Authentication / RBAC** | FUTURE | DEFERRED | Focus strictly on single-analyst workflow first. |
