# SatQuery AI — Future Roadmap

## Phase 1: MVP Core Interaction (Current)
- 3D Globe + Natural Language Query + Automated Camera Tour.
- NDVI vegetation change detection across candidate global regions.
- Structured evidence panel, confidence scores, and real-time execution telemetry.

## Phase 2: Live Remote Sensing Data Ingestion
- Live Sentinel-2 (Copernicus) & Landsat-8 STAC API integrations.
- Dynamic Cloud-Optimized GeoTIFF (COG) windowed tile streaming.
- Dynamic cloud mask filtering using SCL (Scene Classification Layer).

## Phase 3: Multi-Index & Land-Cover Intelligence
- Water expansion (NDWI) and flood impact assessment.
- Urban impervious surface growth (NDBI) and deforestation border tracking.
- Wildfire burn severity (dNBR — Normalized Burn Ratio).

## Phase 4: Multimodal Radar (SAR) & Optical Reasoning
- Sentinel-1 SAR (Synthetic Aperture Radar) backscatter analysis for all-weather & night observation.
- Fusion of SAR coherence with optical NDVI to differentiate weather anomalies from real land changes.

## Phase 5: Geospatial Foundation Models & VLMs
- Integration with specialized Earth Observation VLMs (e.g. Prithvi, Clay, SatMAE, RemoteCLIP).
- Zero-shot visual question answering grounded in raw spectral imagery.

## Phase 6: Voice-Controlled Geospatial Co-Pilot
- Real-time Speech-to-Text (Whisper) and low-latency Text-to-Speech narration for tour playback.
